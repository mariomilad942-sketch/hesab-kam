# الحساب كام

ويب أب عربي ريسبونسيف لتنظيم الأوردر الجماعي وتقسيم الفاتورة. بيشتغل على الموبايل والديسكتوب، وتقدر تضيفه للشاشة الرئيسية زي التطبيق.

## فيه إيه

- **الهوست بيعمل قعدة** بطريقتين: يبعت لينك أو QR والشلة تكتب طلباتها، أو يكتب طلبات الكل بنفسه من موبايل واحد.
- **تايمر:** بيقفل الطلبات، والهوست يقدر يزوّد الوقت.
- **إدارة الطلبات:** طلب يدوي، تعديل، حذف. ولو العضو اتحذف طلبه وعايز يطلب تاني، الهوست يوافق أو يرفض.
- **الطلب المجمّع للمطعم:** بيتنسخ للواتساب.
- **الفاتورة:** ضريبة وخدمة بالنسبة، وديليفري وخصم وأي زيادات تانية بالتساوي، والتقسيم يا بالتساوي يا كل واحد حسب طلبه.
- **مين دفع ومين لسه:** كاش أو إنستاباي. زرار «فكّره» بيفتح واتساب برسالة فيها حسابه، والعضو يقدر يقول «حوّلت» أو «هدفع كاش» والهوست يأكد.
- **فاتورة جاهزة للمشاركة.**

## هيكل المشروع

```
src/core.js      حسابات الفاتورة والتنسيق (أرقام عربي)
src/stores.js    التخزين: محلي / Supabase / Claude artifact
src/app.js       كل الشاشات والتفاعل
src/styles.css   الهوية والتصميم
scripts/build.js بيطلّع web/index.html
web/             ده اللي بيترفع على الاستضافة
supabase/schema.sql
```

## التشغيل على النت (حوالي ١٥ دقيقة، ببلاش)

1. **Supabase (الداتابيز):**
   1. اعمل حساب على supabase.com، وبعدين New project.
   2. افتح SQL Editor، والصق محتوى `supabase/schema.sql`، ودوس Run.
   3. من Project Settings ← API انسخ `Project URL` و`anon public key`.
2. **الإعدادات:** حطهم في `web/config.js`.
3. **الاستضافة على Vercel:**
   1. اعمل حساب على vercel.com، وبعدين Add New ← Project.
   2. ارفع فولدر `web` (أو اربط الريبو واختار Root Directory = `web`)، وFramework = Other، ومفيش Build Command.
   3. دوس Deploy، وهيطلعلك لينك زي `hesab-kam.vercel.app`.
4. **دومين (اختياري):** من Vercel ← Domains.

## التطوير

```bash
node scripts/build.js        # يبني web/index.html و dist/artifact.html
npx serve web                # جرّب محلياً
```

من غير Supabase، التطبيق بيحفظ على نفس الجهاز. عشان تجرّب الهوست والعضو على جهاز واحد، افتح اللينك في تاب تانية وحط `m` قبل الكود، مثلاً `#m4729`.
